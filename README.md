## Acerca de EnfoqueBalanc

*Organiza tu tiempo. Equilibra tus finanzas.*

Una agenda personal que reúne tareas, calendario, notas y control financiero local. Incluye acompañamiento con inteligencia artificial en el dispositivo para ayudar a convertir actividades extensas en pasos pequeños y ofrecer orientación contextual.

La presentación pública describe el producto y su uso. No contiene el código fuente completo, el modelo de IA ni una estructura de proyecto lista para compilar. EnfoqueBalanc funciona en modo local; la sincronización entre dispositivos y las suscripciones no están disponibles en esta etapa. No hay instaladores publicados todavía.

## Tecnologías

Flutter y Dart para Android y Windows; llama.cpp para ejecutar localmente un modelo Qwen. Los datos de agenda y finanzas se guardan cifrados en el dispositivo.

## Organización del portafolio

- `docs/`: sitio público, presentación de proyectos, guía y capturas sin información personal o financiera real.
- `proyectos/agenda-inteligente/`: ficha pública y límites de disponibilidad de EnfoqueBalanc.
- Releases: se usarán para instaladores firmados y versiones verificadas cuando estén listas.

Este portafolio es de presentación y distribución. Ninguna de las aplicaciones se publica como software de código abierto. Los avisos y licencias de dependencias y modelos de terceros se mantienen con sus respectivas versiones.
